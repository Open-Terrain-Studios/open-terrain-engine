# Contributing to Open Terrain Engine

Thanks for your interest in Open Terrain Engine (OTE). This document explains how to engage with the
project and — importantly — what kinds of contributions we can and can't accept.

> **TL;DR:** Issues, bug reports, and feature ideas are very welcome. We do **not** accept code pull
> requests at this time. Please don't open a PR with code changes — see
> [Why we can't accept code right now](#why-we-cant-accept-code-right-now).

## How you can help

- **Report bugs.** Open an issue with steps to reproduce, expected vs. actual behavior, your OS, and the
  engine version/commit.
- **Request features.** Open an issue describing the problem you're trying to solve (the *why*), not just
  the implementation you have in mind.
- **Ask questions and discuss.** Use issues (or Discussions, if enabled) for design questions, usage help,
  and ideas.

When filing an issue, please describe the problem in prose. Avoid pasting large code patches or full
diffs — see [Code in issues](#code-in-issues) for why.

## Why we can't accept code right now

Open Terrain Engine is **source-available under the [Business Source License 1.1](LICENSE)**, and Open
Terrain Studios offers separate **commercial licenses** for uses the BSL doesn't permit. To be able to
license the engine commercially, Open Terrain Studios has to own — or hold the necessary rights to —
**100% of the code in this repository.**

If we merged code written by people outside the studio without a signed contributor agreement, we'd no
longer fully own the codebase, and we couldn't honestly offer the commercial license that helps fund the
engine's development. Rather than ask every contributor to sign paperwork at this stage, we keep code
authorship in-house.

So: **pull requests that change code will be closed unmerged.** This isn't a judgment on your work — it's
a licensing constraint. We may revisit this and introduce a formal Contributor License Agreement (CLA) in
the future; if we do, we'll update this document.

## Code in issues

If you include a code snippet in an issue to illustrate a bug or a suggestion, please keep it minimal. By
posting any content in an issue or discussion (including code snippets, descriptions, or designs), **you
grant Open Terrain Studios a perpetual, irrevocable, worldwide, royalty-free license to use, reproduce,
modify, and incorporate that content** into the Licensed Work and related materials, without obligation or
attribution. If you can't grant that, please describe the issue in words instead of pasting code.

## Security issues

**Please do not report security vulnerabilities in public issues.** Instead, email
**security@openterrain.studio** with details and steps to reproduce. We'll acknowledge your report and work
with you on a coordinated disclosure.
